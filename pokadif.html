📖 How to play
  • Two pictures look the same — but a few things changed. Poke each change, in either picture.
  • 🌱 Basic: 🎨 colours + ➖➕ missing / extra things · 🐣 Junior adds 📏 size + 🔺 shape · 🔦 Intermediate adds 🔄 turn / flip + 🔢 count.
  • 🔍 Magnifier: stuck? It shows you one change (a few per picture).
  • A wrong poke is just an "oops" — but fewer oops = more ⭐. 💀 Hardcore: no magnifier, 3 oops and the case is lost.
  • Every picture is new — made up on the spot, never the same twice!
